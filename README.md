# CoRL Snapshots

This repository stores dated snapshots of the local CoRL workspace.

Snapshot layout:

- `snapshots/YYYY-MM-DD/CoRL/`
- `snapshots/YYYY-MM-DD/SNAPSHOT_MANIFEST.md`
- additional same-day snapshots may use `YYYY-MM-DD_2`, `YYYY-MM-DD_3`, etc.

Large generated training outputs are intentionally excluded from GitHub snapshots.
