목적은 단순히 nested `risky` repo 일부만 올리는 것이 아니라, "layout에서 전체 파이프라인이 작동하는 상태"를 복구 가능한 형태로 남기는 것이다.

이번 snapshot에는 다음 변경들이 함께 포함된다.

- subgoal puddle disable 기본값을 60 step으로 맞춘 layout/config 변경
- transplant HSP 실험 기본 episode length 200 적용
- subgoal activation 직후 timer가 같은 transition에서 바로 감소하지 않도록 한 Risky MDP 보정
- `risky_multipath_subgoal` 기반 HSP S1 실행 command와 hidden utility 설정 기록
- 오늘 기준 paired HSP run을 재현할 수 있는 script/config/policy pool 구조

### 기존 환경인 HSP에서는 어떤 것을 사용하거나 수정했는가

HSP repo 자체를 upstream으로 따로 push하지 않고, CoRL snapshot 안에 현재 workspace 상태로 포함했다.

사용한 HSP 쪽 요소:

- HSP algorithm code 구조
- policy pool / MEP / HSP S1 학습 절차
- `03_train_hsp_s1_risky.sh`에서 호출되는 HSP-style training pipeline
- 기존 policy/config artifact 중 transplant 파이프라인 재현에 필요한 항목

주의:

- HSP env를 Risky 실험의 source of truth로 삼은 것은 아니다.
- HSP env의 shaped-info event 이름을 Risky event 기준으로 사용하지 않는다.
- GitHub CLI `gh`가 설치되어 있지 않아 PR 방식이 아니라 기존 snapshot repo의 `main`에 직접 push했다.

### 기존 환경인 risky에서는 어떤 것을 사용했는가

Risky 쪽은 전체 파이프라인 snapshot 안에 현재 작업 상태로 포함했다.

포함된 핵심 내용:

- `risky/src/risky_overcooked_py/data/layouts/`의 subgoal layout 값
- `risky_multipath_subgoal` 및 `risky_multipath_subgoal_tomato`
- `risky/src/risky_overcooked_py/mdp/overcooked_mdp.py`의 subgoal timer activation 보정
- Risky `EVENT_TYPES` 기반 hidden utility feature 연결

주의:

- nested `risky` repo 자체는 별도 upstream push 대상이 아니었다.
- 최종 source of truth는 `dhwngus111-alt/CoRL`의 dated snapshot이다.
- Risky legacy study model 산출물은 이번 snapshot에서 제외했다.
